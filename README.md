# QOL-OBSDN-PLGNS
## General Information
### <u>1.1 Introduction</u>

**Quality Of Life Obsidian Plugins**.

This is a collection of simple Obsidian plugins designed to bring solutions to niche/nitpicky problems which I have faced while working, and decided to share with you.

All of these are have been personally hand-written, and the only use of AI in this repository was for researching components within Obsidian. It has not been used elsewhere or for any other purpose.
